# Review Gates

Codex may continue autonomously between gates. Stop and request owner action at the following points.

## Gate A — Architecture and privacy

Before implementation beyond the scaffold, confirm:

- private single-user access approach;
- database and raw-upload storage choice;
- expected free/paid service costs;
- no requirement for local user development;
- no real data committed to Git;
- Production remains disabled or inaccessible.

## Gate B — First real-data import

Before importing the owner’s full private exports into a hosted environment, provide:

- schema summary;
- retention and deletion behaviour;
- access controls;
- estimated storage/processing costs;
- rollback plan;
- confirmation logs will not expose source rows.

## Gate C — Analytical baseline

Before presenting recommendations as actionable, provide holdout results for:

- time/speed benchmarks;
- discovery ranking;
- tournament qualification ranking;
- confidence calibration;
- simple-baseline comparison.

Low-performing or unvalidated models must remain labelled experimental.

## Gate D — Maiden recommendations

Before enabling final “Enter this Maiden” recommendations, demonstrate:

- ME lifecycle tests;
- cross-mode opportunity-cost logic;
- preserve-ME behaviour;
- bracket-specific recommendations;
- commitment warning.

## Gate E — Breeding recommendations

Before presenting breeding recommendations as more than exploratory, demonstrate:

- all rule-engine tests;
- family restriction correctness;
- class, element, F-number and fee calculations;
- chronological parent-offspring validation;
- separation of elite-upside and vault-fit scores;
- honest uncertainty reporting.

## Gate F — Production activation

Require explicit owner approval before:

- enabling Production;
- attaching a custom domain;
- uploading full private data to Production;
- enabling recurring paid infrastructure;
- inviting another user;
- exposing any public route or API.

## Always-stop conditions

Stop immediately for direction if work requires:

- a secret or account action;
- a new paid service;
- irreversible production data change;
- weakening privacy;
- scraping authenticated game content;
- automatic game transactions;
- changing confirmed game rules;
- uncertainty that materially changes a recommendation.
