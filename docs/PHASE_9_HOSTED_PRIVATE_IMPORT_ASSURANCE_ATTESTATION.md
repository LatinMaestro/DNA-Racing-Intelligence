# Phase 9 hosted private import assurance attestations

## Scope

Bind representative private real-file import assurance to one exact candidate
head without retaining private rows in Git or routine evidence artifacts.

Required coverage is:

- 18,127 Core Details rows with lineage;
- 195 owner-confirmed Windows-1252 Vault rows;
- 792 Arena snapshot rows; and
- all six sequential Race Merge files containing 2,536,710 rows.

## Required controls

Evidence must cover Core Details/lineage, Windows-1252 Vault, Arena, full-volume
Race Merge processing, append ordering, boundary deduplication, replay, older
backfill, replacement snapshots, rollback, malformed/conflict quarantine,
freshness, provenance and bounded memory.

Every control is bound to reviewed source, import-contract and aggregate-profile
digests, fixed commands, exact UTC bounds, complete assertions and the same exact
head.

## Private boundary

Execution must occur in an authenticated owner workspace. Original files and
source values remain preserved inside the approved private raw-data boundary.
Routine logs and retained attestations contain redacted, aggregate evidence only.
No private row, filename, checksum, durable ID, economic value or derived
owner-specific output may enter Git.

## Authority boundary

Missing connected execution remains review-required. The contract does not
upload, activate or persist a source, mutate a provider, dispatch Actions, merge
or enable Production.
