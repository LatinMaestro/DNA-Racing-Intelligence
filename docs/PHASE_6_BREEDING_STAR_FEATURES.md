# Phase 6 Breeding Star Features

## Purpose

Build auditable parent and lineage Gold/Blue research features for chronological
offspring testing without treating star propensity as inherited quality.

## Contract

- Keep Bike, Car and Horse and every exact distance separate.
- Preserve Gold, Blue and strong-field numerators and denominators.
- Use only evidence whose event cutoff predates breeding.
- Exclude stale, unknown, partial, invalid and wrong-cell evidence.
- Keep zero opportunity distinct from a zero assignment rate.
- Require a configurable minimum denominator before describing a lineage profile
  as above a pre-breeding population benchmark.
- Keep `Data current through` separate from `Last imported`.
- Require one accepted direct profile for each parent before a pair is ready for
  chronological testing.

## Boundaries

An above-benchmark lineage profile is a research feature, not an inherited trait
or an offspring-quality claim. This contract does not score, rank or recommend a
pairing and cannot pass Gate E.
