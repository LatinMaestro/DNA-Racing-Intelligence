# Phase 6 Breeding Pair Ranking

## Purpose

Present imported breeding evidence on the three approved dimensions without
allowing Vault saturation to hide a rare high-upside pairing. These are
experimental review orders, not pairing recommendations or predictions of a
guaranteed offspring outcome.

## Version and rule binding

- Bind every ranking and candidate to the exact confirmed ruleset, candidate
  snapshot, chronological projection and applicable Arena snapshot versions.
- Derive the displayed offspring class through the confirmed class matrix, the
  lower-ranked parent element and the uncapped sum of both parent F-numbers.
- Require confirmed family, sex-compatibility, cycle, lifetime-splice-capacity
  and parent-availability evidence before a pair enters any order.
- Validate the declared owned/owned, owned/Arena or Arena/Arena source against
  parent ownership. Duplicate parent pairs are rejected regardless of order.
- Use the latest accepted Arena snapshot only for external parents, retain the
  listing expiry and hold expired, stale, missing or mismatched evidence.

## Ranking contract

- Publish separate elite-upside, Vault-gap and balanced rankings.
- Rank elite upside first by the experimental exceptional-outcome estimate and
  never by Vault fit.
- Rank Vault-gap improvement independently from elite upside.
- Calculate the balanced view from explicit integer basis-point weights.
- Preserve exact mode, distance in metres, parent identities, confidence,
  accepted cutoffs and import times.
- Hold uncalibrated offspring distributions and evidence without supported
  chronological parent-offspring validation.
- Star features may enter only after supported incremental chronological
  holdout lift over a time-only baseline.

## Boundaries

Freshness labels are derived from accepted cutoffs and server time by the read
service; stored labels are not trusted. Arena listings are historical imported
availability evidence, never live state and never proof of breeding income or
expense.

The contract consumes compact audited evidence and does not discover a hidden
formula, mutate breeding state or create an economic transaction. Rankings
remain experimental and cannot authorise a pairing before Gate E.
