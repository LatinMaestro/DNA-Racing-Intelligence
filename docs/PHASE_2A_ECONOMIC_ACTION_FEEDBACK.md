# Phase 2A Economic Action Feedback

## Scope

This boundary projects privacy-safe, accessible feedback for staged manual
ledger, tournament payout, breeding, offspring cost-basis, sale, burn and
actual burn-credit actions. It does not enable any form or connect persistence.

## Contract

- Accept only fixed operation, outcome and invalid-field enums.
- Render failures as semantic assertive alerts and other outcomes as polite
  status regions.
- Show reviewed field labels, never submitted values or raw exception text.
- Distinguish recorded evidence, exact durable replay, review-required evidence
  and durable conflicts.
- Keep unavailable identity and forced-RLS persistence explicit.

## Deferred activation

Server Actions must translate strict parser and repository outcomes into this
projection without passing arbitrary error messages. Forms remain disabled
until parsing, owner verification, forced-RLS Preview persistence and accessible
feedback are wired and validated together. No wallet, game, provider or
Production operation is enabled.
